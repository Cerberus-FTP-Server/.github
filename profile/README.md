# Cerberus FTP Server

> Cerberus FTP Server keeps authorized shares on one Windows host: open the user accounts, pin the file shares, and leave the transfer log on the same own host.

---

## Session Card

| Slice | What you do in Cerberus FTP Server | What remains |
|-------|------------------------------------|--------------|
| Arrival | Open Cerberus FTP Server and name today's own host | A titled host |
| Focus | Keep only live accounts on Cerberus FTP Server user accounts | A short account list |
| Shares | Open Cerberus FTP Server file shares for folders you are authorized to run | A share note |
| Log | Open Cerberus FTP Server transfer log for the same host | A log note |

| Handoff | Mark finished shares inside Cerberus FTP Server | A note for the next visit |

## Four Beats

1. **Name the host.** Give the Cerberus FTP Server own host a short title before you open a folder you do not run.
2. **Pin the live accounts.** Keep current names on Cerberus FTP Server user accounts and leave unused hosts aside.
3. **Read the shares.** Open Cerberus FTP Server file shares only for machines and folders the reader is authorized to run.
4. **Check the log.** Read Cerberus FTP Server transfer log before you archive a share.
5. **Close the loop.** Clear finished shares so the next Cerberus FTP Server visit does not start with a search.

## First Questions

**Does Cerberus FTP Server replace every other program?**
No. Cerberus FTP Server sits beside the file desk, browser, and hosts you already run.

**Can two people share one computer?**
Yes. Each person keeps a separate Cerberus FTP Server profile.

**What should a new user try first?**
One small Cerberus FTP Server user account today, then the same transfer log tomorrow.

**Does the transfer log leave the own host?**
No. Cerberus FTP Server transfer log stays with Cerberus FTP Server file shares on that host.

**Which folders belong on this host?**
Only machines and folders the reader is authorized to run. Cerberus FTP Server is not a door into someone else's share.

## Who Sits Down at Cerberus FTP Server

- **User accounts** — names stay on Cerberus FTP Server user accounts.
- **File shares** — paths stay on Cerberus FTP Server file shares.
- **Transfer log** — traffic stays on Cerberus FTP Server transfer log.
- **Own host** — the name stays on one Cerberus FTP Server board.
- **Handoff** — the next admin can read the Cerberus FTP Server note without a tour.

## Field Note

Cerberus FTP Server is easier to trust when the own host stays smaller than the folder it came from. A named host shows what is active, the account pins show who may enter today, and the closing note tells the next admin which share changed.

## One Real Pass

Pick a host that already has a name. Open it in Cerberus FTP Server, keep only authorized accounts on the list, and finish one transfer log you can see.
